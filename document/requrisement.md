ploblem : ฉันทำงานเป็น reporter สร้างและจัดเก็บข้อมูลต่าง ๆ ของรายงาน รายงานของฉันสร้างด้วย xml และแสดงผลเป็นหน้า ui บ้าง หรือส่งออกข้อมูลเป็น excel และ pdf
ปัญหาเกิดขึ้นเมื่อมีคนใช้มากขึ้น หลายคน หลายแผนก และรายงานก็เยอะขึ้น ทำให้บางครั้ง ต้องสร้างรายงานใหม่ทุกครั้งที่มีการขอสร้างรายงานเข้ามา ทั้ง ๆ ที่มันอาจจะเป็นรายงานที่ใกล้เคียงกับอันที่มีอยู่แล้วก็ได้


solution : ฉันจึงต้องการระบบที่สามารถเข้ามาช่วยฉันตรงนี้ได้เพื่อเพิ่มความสะดวกในการจัดการรายงาน และเพิ่มความง่ายให้ผู้ใช้ในการหารายงานที่ต้องการ
โดยจะแบ่งเป็น 2 ส่วน
1. ผู้ใช้ 
- สามารถเข้ามาค้นหารายงานที่ตัวเองต้องการได้
- สามารถดูตัวอย่างข้อมูลได้
- สามารถโหลดฟอร์มรายงานเปล่าไปใช้งานได้
- สามารถส่งออกข้อมูลตัวอย่างได้
- สามารถ บุ๊คมาครายงานโปรดของตัวเองเพื่อให้หาง่ายๆ ได้
- สามารถมองเห็นแค่่รายงานที่ตัวเองมีสิทธิตามที่กำหนดเท่านั้น

2. แอดมิน
- สามารรจัดการข้อมูลรายงานได้ เพิ่ม ลบ แก้ไข
- สามารถเพิ่มรายละเอียดของรายงานได้
    - ชื่อรายงาน-
    - ชื่อไฟล์ที่อัพโหลด ทั้งไฟล์รายงาน *.jasper / pdf / ตัวอย่างข้อมูล
    - ฟอร์มเปล่าแบบ pdf 
    - ข้อมูลตัวอย่าง
    - ตัวแปรที่ใช้ในรายงาน
    - คิวรี่ที่ใช้ในรายงาน อาจจะมีมากว่า 1 ชุด และเป็นคิวรี่ หลัก ได้ 1 เท่านั้น
    - กำหนดสิทธิการเข้าถึงแบบละเอียดต่อ 1 รายงาน แบบ บุคคล หรือแบบบทบาท
    - สิทธิ แก้ไข ลบ เพิ่มรายการโปรด มองเห็น ส่งออกข้อมูล พิมพ์ฟอร์มเปล่าได้ เป็นต้น
    - ควบคุมด้วยเวอร์ชั่น ทั้ง คิวรี่ ไฟล์
- สามารถดู log ต่าง ๆ ได้ ทั้ง เพิ่ม ลบ แก้ไข และการกระทำต่าง ๆ
- มี dashboard แสดงถึงการใช้งาน รายงาน

3. เพิ่มเติม 
- มีการยืนยันตัวตน
- เข้าสู่ระบบ สามารถตั้งค่าได้ เช่น จาก api / database / email
- สามารถปรับแต่ง ธีมได้ มืด / สว่าง
